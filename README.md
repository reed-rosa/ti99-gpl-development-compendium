# TI-99/4A GPL Development Compendium

This repository contains a tested companion collection for **Davvel's GPL Development series** on AtariAge.

Davvel did something that had been badly needed in the TI-99/4A community: instead of simply documenting GPL or describing how it worked, he wrote a series of practical **HOW-TO articles showing how to actually write GPL programs**.

The original discussion and tutorial series can be found here:

https://forums.atariage.com/topic/248039-gpl-development/

## About this compendium

As I worked through Davvel's articles, I found that some examples were instructional fragments rather than complete programs, and the series was not always consistent about providing a compilable version of the code or showing the resulting output.

I spent considerable time going through the examples individually, completing or correcting them where necessary, assembling them, and verifying that they actually worked.

This repository contains those tested examples in a single archive.

## Download

Download the ZIP file in this repository to get the complete GPL development compendium and working examples.

## Purpose

The intent of this project is not to replace or rewrite Davvel's original work.

Davvel's articles provide the **explanation, context, and HOW-TO instruction**.

This compendium provides the **tested code and examples that can be assembled and run**.

For anyone interested in learning GPL programming on the TI-99/4A, I recommend reading the original AtariAge series alongside these files.
